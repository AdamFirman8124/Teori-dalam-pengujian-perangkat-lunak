# Adaptasi Interface Generator

| Tool | Adaptasi untuk backbone modern | Kategori |
|---|---|---|
| CoverUp | Model dan endpoint diganti lewat konfigurasi LiteLLM; isi prompt tidak diubah. | tidak ada |
| CodaMOSA | Payload legacy completions dipetakan ke chat-completions; isi prompt dan target pengujian tidak diubah. | interface-only |
| Pynguin | Tidak memakai LLM. | n/a |
| MuTAP | Dikelola kolaborator dan tidak dijalankan pada mesin ini. | diisi kolaborator |

Kategori ini bersifat deskriptif. Sesuai rancangan Bab IV, RQ2 tidak mengklaim
bahwa perubahan efektivitas disebabkan oleh adaptasi prompt. Adaptasi yang sama
digunakan untuk B1 dan B2 dalam satu tool.
